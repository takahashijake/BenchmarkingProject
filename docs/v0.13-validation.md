## Scientific comparison

Separate baseline and feature interpreters ran deterministic binary, multiclass,
and regression nested searches with two outer folds, two inner folds, two trials,
a fixed reference and a two-trial final stage. Full semantic outputs, including
fingerprints, metrics, predictions, proposals, trial outcomes, parameters,
selection scores, ranks and final selection, were exactly equal after excluding
runtimes. The canonical comparison JSON SHA-256 was
`1994e1f015fcfc088a37a78b131fde95567d419065edb4be2b7c22c240973034`.
New recovery tests also compare cached/mixed execution against independent
uninterrupted execution. This equality is environment-specific evidence, not
an assertion of cross-dependency bitwise numerical stability.

## Adversarial review and regression coverage

`tests/test_search_recovery.py` tests all three tasks, fixed and multiple searched
families, optional/fixed final selection, failed trials, family failures and
all-failed semantics. Fit prohibition and counters prove completed computation
is reused. Sealed search/AutoML artifacts pass deep verification and catalog
checks. AutoML's canonical plan and fingerprint remain stable; changing allocation
remainder while preserving per-study allocation invalidates its workspace.

Six actual child-process SIGKILL cases cover search and AutoML during a study,
after temporary-file fsync but before task rename, and before artifact sealing.
A bounded pipe/select handshake supplies deterministic synchronization without
sleep-based timing assumptions. Recovery reuses exactly the committed task count
and matches uninterrupted scientific outputs. A separate process owns the lock
in the simultaneous-access test.

Corruption cases include truncated/duplicate JSON, null/nonfinite/extra payloads,
bad checksums and schema/contracts, malformed prediction indices/duplicates/truth,
metrics, counts, selection, trial parameters, inner plans and seeds. Payloads are
rehashed in semantic-adversary tests, proving that checksum validation alone is
insufficient. Dataset content/target metadata, model parameters, seed, metrics,
fold order, final folds, space version/defaults, provider declarations and AutoML
plan changes invalidate compatibility. Unexpected members and symlink tasks,
temporary files, lock paths and ancestors fail closed. Output relocation remains
compatible. Publication validation failures abort rather than marking a model as
scientifically failed.

One preflight regression initially found that an empty custom search registry
failed resolution before the recovery-specific version-contract rejection. The
registry check was moved before dataset/fold/search resolution; the original
rejection assertion was retained. No tests were weakened.

Shared byte-publication helpers were extracted without changing fixed benchmark
identity, checkpoint schema, payload, locking, or supervision semantics. Existing
parallel, hard-timeout, provider, historical artifact, catalog, leakage, search and
AutoML regressions remain in the full suite. The installed-wheel smoke now also
creates/resumes pinned-provider search checkpoints from outside the checkout.

## Sampler/storage experiment

Installed Optuna 5.0.0 source initializes independent sampler RNG and startup
random-sampler state in `TPESampler`; `Study.add_trials()` imports trial history,
not these random states. A local seeded 12-trial experiment confirmed the design
boundary: continuous trial 13 proposed `x=0.7364482740906375`, while both a fresh
seeded sampler with reconstructed history and a reopened SQLite-backed study
proposed `x=0.6944565845532206`. Durable Optuna history alone therefore did not
provide exact continuation. This experiment used no estimator fits and no
persistent repository files.
