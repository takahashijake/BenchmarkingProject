# v0.15 verification-gated reporting

## Architecture decision (recorded before implementation)

Baseline: fetched `origin/main` at `5220b8a1bf0c9be937348fafd0ecf81b1ee2c479`,
with a clean working tree. Reviewed merged PRs #5 (providers), #7 (durable
search/AutoML), #8 (parallel search), the historical catalog correction #6,
README, changelog, architecture, provider contracts, validation reports, storage,
verifier/descriptors, analysis, CLI, regression tests, CI and wheel smoke.

Persisted workflow configurations use schema 1. Robustness explicitly records
artifact schema 1; historical other workflows may omit that field. Manifests use
schema 1; catalog SQLite uses user_version 1. Fixed and nested-search recovery
workspaces have their own versioned schemas and are not reportable experiments.
The five stores write JSON/CSV, then seal. Their existing readers return mutable
mappings and some load predictions unnecessarily for presentation. The verifier
already validates all member JSON/CSV, topology, redundancy, metric aggregates,
identity, nested evidence and optional prediction/statistics recomputation. It
returns the normalized descriptor used by the catalog. No new serialization,
scientific identity, scoring, ranking or recovery format is needed.

Implement `reporting` downstream of `artifacts.verify.verify()`:

1. Loader: require a successful ordinary/deep verification, then adapt descriptor
   and selected JSON summaries. Do not load original datasets, execute providers,
   fit estimators, run studies or deserialize executable objects. Explicit opt-in
   admits only historical unsealed artifacts already accepted by the verifier;
   it never excuses a missing modern seal or another verification failure.
2. Model: frozen dataclasses, tuples and canonical JSON snapshots for polymorphic
   configuration/provenance. Preserve absent historical fields as unavailable.
   Carry metrics/directions, candidates/status, folds/repetitions, trial counts,
   selection, robustness and diagnostics separately. No mutable dict escapes.
3. Presentation: deterministic semantic HTML with inline CSS, no JavaScript,
   remote assets or generated timestamp. Escape every evidence string, including
   JSON, paths and identifiers; replace malformed Unicode for UTF-8 output.
   Show stored outer scores in nested leaderboards. Inner and final selection
   scores are explicitly selection-only. Reuse robustness interpretation code.
4. Publication: validate both inputs and destination, reject symlink paths and
   artifact/workspace ancestors, stage/fsync beside the destination, then publish
   atomically without clobbering by default. Explicit overwrite uses replacement.
   Clean temporary output on all exceptions. Never stage inside evidence.
5. Comparison: call existing pure `catalog.compare_descriptors()` directly;
   require no catalog. Add conservative presentation restrictions where its
   historical compatibility contract omits preprocessing/missing methodology.
   Display numerical deltas only for fully compatible evidence; partial status,
   reasons, failures, candidate changes and parameters remain visible.

Keep existing dependency boundaries and package/evaluator version 0.8.0. No
scientific kernel, schemas or fingerprints change. SHA-256 seals detect byte
changes relative to an inventory; they are not signatures of authenticity.
Hostile concurrent filesystem replacement is outside the existing artifact trust
boundary. Reports contain recorded configuration/provenance and should be shared
with that disclosure in mind.

## Validation plan

Establish unchanged full-suite results first. Add real artifacts for all five
workflows and all three tasks, independent stored-value assertions, partial and
failed evidence, ties, minimizing metrics, legacy/missing metadata, provider
isolation, deterministic bytes and source hashes. Exercise corruption, semantic
adversaries with refreshed seals, malicious presentation strings, symlinks,
publication failures, CLI and installed-wheel execution. Retain Python 3.12/3.13
CI and portable Windows execution; extend wheel smoke to offline HTML. Record
actual outcomes separately from planned gates.
