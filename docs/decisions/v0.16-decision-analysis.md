## Scientific procedure

`load_decision_config` / `run_decision_analysis`, and `benchforge decision CONFIG`.
Binary classification, fixed built-in candidates, serial execution only. Reject
providers, unsupported tasks/estimators, execution/recovery/search options and
nested estimator parallelism before fitting. Every candidate shares one exact
outer plan and its training-only nested plans. Preflight every inner and
calibration split, including both classes, before any fit.

Each inner fold fits a fresh full preprocessing/estimator pipeline inside the
inner-training boundary and emits probabilities only for inner validation.
Calibration none requires predict_proba. Sigmoid/isotonic use sklearn
CalibratedClassifierCV with explicit `ensemble=False`, `n_jobs=1`, and persisted
stratified calibration splits relative to the permitted training rows. This
cross-fits raw scores with fresh preprocessing, fits a calibrator on training-only
OOF raw responses, then refits the base pipeline on that training boundary.
The fitted calibrator never sees inner/outer validation observations. No prefit
calibrator or preprocessing outside calibration CV. The response preference
(decision_function before predict_proba) and dependency versions are explicit.
Final outer refit repeats the procedure using outer training only.

Isotonic requires at least 1000 pooled calibration observations at every fitting
boundary (the single calibrator uses pooled OOF responses with ensemble=False),
plus sufficient observations of each class for stratification. This conservative
sample floor does not establish adequacy under severe imbalance. Method is
precommitted, never chosen from outer performance. Probabilities explicitly mean
P(encoded target=1); retain the original ordered target labels.

Threshold rule is p >= t. Fixed policy defaults to 0.5. Optimize evaluates a
bounded finite explicit grid using inner OOF evidence only; objectives are F1,
balanced accuracy, or (FP_cost*FP + FN_cost*FN)/N. Exact rational comparisons
avoid floating-point objective ties; ties favor decimal distance to 0.5 then the
smaller threshold. Grid order is canonical. The [0,1] boundary cannot express
all-negative predictions when p=1; document this instead of adding an out-of-range
sentinel. Always evaluate a matched fixed-0.5 reference using the same outer
probabilities. Store all per-fold selections, not an averaged deployment cutoff.

Probability quality (Brier, binary log loss with float64 epsilon clipping,
ROC-AUC, uniform reliability bins and descriptive ECE) is separate from threshold
metrics. Bins are left-closed/right-open except the final bin includes 1; empty
bins retain null means. ECE depends on binning and sample size; Brier/log loss
also reflect discrimination, not calibration alone. All leaderboard metrics are
unweighted outer-fold means with existing population-standard-deviation (ddof=0) semantics.
Only fully successful candidates rank; exact score ties share competition ranks.
Partial completed folds and explicit failures remain visible. No inference of
statistical significance, deployment reliability or distribution-shift protection.

## Evidence, identity and publication

Frozen typed results contain tuples/scalars and canonical JSON snapshots for
polymorphic identity inputs. Persist truth, complete global-index outer/inner/
calibration plans, split/estimator seeds, inner probabilities/selection curves,
outer probabilities/predictions, confusion counts, quality bins, aggregates,
failures and completeness. Identity hashes canonical policy, resolved dataset
content digest/label mapping, model identities, seed/split/calibration/threshold/
metric semantics and applicable dependency versions. Paths and runtime excluded.

Stage a complete new directory on the destination filesystem, validate and SHA-256
seal with the existing manifest machinery, then publish; clean staging on caught
failures. Extend artifact type discovery and normalized descriptors additively.
The offline adapter validates strict schemas, exact deterministic plans recreated
from stored truth, training-subset/disjointness constraints, seeds, selection
reconstruction, predictions, confusion/cost/bin calculations, fold metrics,
aggregates and ranking. It never resolves datasets, fits models or activates
providers. Stored fit plans describe the promised execution; JSON cannot prove
that a model was fitted honestly or recover original features. Hash seals are
integrity markers, not signed authenticity.

Catalog compatibility includes complete decision/calibration/binning policy and
dependency/fold semantics. Existing SQLite schema and historical artifacts remain
unchanged; new workflow has no implicit migration. Reports reuse verification,
escaping, static HTML and safe output publication, display selection separately
from outer evaluation and retain all existing offline guarantees.
